## 🛠️ Troubleshooting  
**Issue:** *The app won’t start.*  
- Ensure you extracted the zip completely (not just opened it).  
- Right-click `pdf-edit-tool.exe` → **Properties** → check “Unblock” if present.  
- Temporarily disable antivirus software (some may flag portable apps).  

**Issue:** *“Missing DLL” error.*  
- Download and install the latest [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) from Microsoft’s official site.  

**Issue:** *Can’t open a specific PDF.*  
- The file may be password-protected or corrupted. Try a different PDF to confirm.  

**Issue:** *Edits not saving.*  
- Make sure you have write permissions to the destination folder. Save to your Documents or Desktop instead.  

If problems persist, see the **Support** section below.
